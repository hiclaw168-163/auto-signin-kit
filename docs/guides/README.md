# 操作指南

面向**刚拿到这个仓库的人**: 怎么装、怎么跑、怎么加东西、出问题先看哪。

规范("应该是什么样")在 `docs/standards/`,代码现状("实际是什么样")在
`docs/superpowers/specs/`。本目录只回答"**我要动手,该怎么做**"。

| 文件 | 主题 | 什么时候看 |
|------|------|------------|
| [GUIDE-01-开发者上手.md](GUIDE-01-开发者上手.md) | 装环境、跑命令、日常开发循环、配置分层 | 第一次接触仓库 |
| [GUIDE-02-新增一个域.md](GUIDE-02-新增一个域.md) | 加域/加命令的完整步骤与检查清单 | 要支持一个新的助手 |
| [GUIDE-03-排错手册.md](GUIDE-03-排错手册.md) | 症状 → 原因 → 处理,按报错对号入座 | 命令跑不通、门禁红了 |

只想让签到每天自动跑的话,看根 `README.md` 的
[定时调度](../README.md#定时调度让它每天自己跑)一节就够,不必读本目录。

命名与索引规则见
[STD-06 §2.1](../standards/STD-06-脚本与资产规范.md)(`GUIDE-` 前缀)。
